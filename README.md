# Rosie's Bakery

A responsive bakery ordering application built with React and Vite.

## Live Demo

https://web-foundation-gp4pjwpo0-rosie-faith.vercel.app


![Rosie's Bakery Screenshot](screenshot.png)

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Vercel

## Features

- Dynamic product listing
- Product cards using reusable React components
- Add-to-cart functionality
- Dynamic cart total in FCFA
- Controlled order form
- Phone number validation
- Conditional rendering
- Order confirmation
- Responsive mobile layout

## What I Would Build Next

- Product images
- Quantity controls
- Remove-from-cart functionality
- WhatsApp order confirmation
- Online payment integration
- Admin dashboard for managing orders
